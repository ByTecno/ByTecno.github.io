Política de privacidad de TeknoBrawl Analytics

Última actualización: 19 de noviembre de 2026.

TeknoBrawl Analytics es una herramienta de uso personal del creador del canal de YouTube Tekno - Brawl Stars. Sirve para consultar las estadísticas de ese canal. No es un servicio abierto al público y no la usa nadie más.

Qué datos usa

Con el permiso que da el propietario del canal mediante el inicio de sesión de Google, la herramienta accede solo en modo lectura a:

  • La información pública y privada de los vídeos del propio canal (YouTube Data API).
  • Las estadísticas del propio canal, ingresos estimados incluidos (YouTube Analytics API y YouTube Reporting API).

No accede a datos de otros usuarios ni de otros canales, y no puede publicar, modificar ni borrar nada.

Dónde se guardan

Los datos se descargan y se guardan únicamente en el ordenador del propietario del canal. El token de acceso se guarda en ese mismo ordenador y no se comparte.

Con quién se comparten

Con nadie. Los datos no se venden, no se ceden a terceros y no se usan para publicidad.

Cómo retirar el acceso

El propietario puede retirar el permiso en cualquier momento desde la página de permisos de su cuenta de Google. Para borrar los datos ya descargados basta con eliminar la carpeta local de la herramienta.

Uso de los datos de las API de Google

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado. Al usar las API de YouTube también se aplican las Condiciones del servicio de YouTube y la Política de privacidad de Google.

Contacto

Para cualquier duda, escribe a través del canal de YouTube Tekno - Brawl Stars.
